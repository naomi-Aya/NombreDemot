# Word Counter en Java

Ce projet est un programme Java permettant de compter le nombre total de mots contenus dans un fichier texte.

---

## Fonctionnalités

- Lecture d’un fichier texte avec `File` et `Scanner`
- Lecture ligne par ligne
- Séparation des mots avec les espaces
- Comptage automatique des mots
- Affichage du nombre total de mots

---

## Technologies utilisées

- Java
- IntelliJ IDEA

## Exécution du programme

### 1. Compiler le fichier

```bash
javac Main.java
```

### 2. Exécuter le programme

```bash
java Main
```
